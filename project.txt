
-> Users
    -> user_type => administrator
    -> user_type => dispatcher
    -> user_type => driver


-> Vehicles (vozila)
    -> type
        -> truck, van, car
    -> plate_number
    -> brand
    -> model
    -> year
    -> mileage
        -> default 0
    -> status
        -> available, in_use, maintenance, inactive
    -> user
        -> nullable
        -> OneToOne
    -> workhours -> default: 0
    -> capacity


-> VehicleLog
    -> Koje vozilo je preuzeo
    -> Ko je kada preuzeo neko vozilo
    -> Koliko je kilometara presao
    -> Kada je vratio vozilo

-> Country
    -> Name

-> City
    -> Name
    -> Country

-> Company
    -> name
    -> City
    -> created_at


-> Shipments
    -> title "Jabuke za ABC DOO"
    -> description "Treba dostaviti jabuke od A to B"
    -> company
    -> pickup_location
        -> City, odakle se uzima?
    -> delivery_location
        -> City, dokle ide?

    -> price
        -> Koja je cena posiljke?

    -> status
        -> pending/canceled/enroute/delivered
        -> default: pending

    -> created_at
        -> Kada je napravljena
    -> scheduled_at
        -> Kada je pickup?
    -> deadline
        -> do kada treba dostaviti?

    -> dispatcher
        -> Koji dispatcher je dodeljene?
            -> Povezano sa user

    -> driver
        -> koji driver je dodeljen?
            -> Povezano sa user

    -> vehicle
        -> koje vozile se koristi ?
            : Mozda se vozac razboli ili nesto, a vozilo ostane isto

    estimated_distance
        -> koliko u KM je rastojanje?
            -> Koristicemo Google API da proverimo ovo

    notes
        -> Mozda neki note? "Klijent ne voli ako se vozi brzo"


Invoices
